# Illustration brief

These three generated concept sheets were created on 7 November 2026 with OpenAI image generation. Each sheet contains the base class on the left and its two selected paths in the order documented in the [class guide](README.md). They are references for art and UI exploration; production models, animation, hit areas and equipment must be made separately.

## Shared prompt direction

Landscape triptych of three full-body versions of the same adult hero, equal scale and spacing, standing in dark forest twilight. Angular faceted low-poly 3D game style, matte wood, linen, leather and metal, cream embroidery, oxblood, soot, moss and bronze. Economical detail suitable for a mobile game. No labels, cards, logos, watermarks, photorealism, heavy fantasy armor or excessive particles.
