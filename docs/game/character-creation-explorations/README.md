# Character creation concepts

These three portrait illustrations continue from the empty place at the selected campfire character-selection screen. They show one compact, icon-led creation flow rather than three separate menu designs.

| Step       | Illustration                           | Open controls                                                                                                                               |
| ---------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Appearance | [01-appearance.png](01-appearance.png) | The hero preview moves closer; hair choices and color swatches are visible. Body, face, and moustache belong in this same appearance group. |
| Class      | [02-class.png](02-class.png)           | Full-body hero preview for the three classes. This older illustration still has the former «Лицар» label baked into the artwork.            |
| Name       | [03-name.png](03-name.png)             | A carved wooden name input, reroll icon, and a compact carved relic button with an engraved forward rune.                                   |

The three bottom glyphs switch between steps. Only the current choice group is open, keeping the scene and character readable. These are visual studies, not implemented UI. The sample hero, appearance, and name are illustrative; runtime choices must reflect the actual creation state.
