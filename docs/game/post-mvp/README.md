# Post-MVP game features

| Salt Road: salt-cart chase quest | Planned, post-MVP | Cart movement/drifting, obstacle collisions, cargo projectiles, multiplayer pursuit and tactical PvP handoff | [Quest design and two illustrations](salt-road/README.md) |

Prototype the driving and escape loop with scripted riders before adding live player pursuit. Multiplayer readiness and the quest's reward/loss rules need separate decisions before production implementation. Follow the shared [visual and reach guidelines](../design-guidelines.md).
